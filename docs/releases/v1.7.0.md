## v1.7.0：广播回复首屏与抓取恢复修复

### 本人广播回复首屏（#26）

- 概览新增“保存广播回复首屏”，**默认关闭，仅限当前登录者自己的账号**；重开面板后需重新勾选。
- 对有回复的本人 status 和已支持的 personal topic，分别保存详情 HTML 与一个回复 API 首屏。
- 增量补历史未成功项；“重新抓取可编辑内容”刷新已知首屏与可编辑 topic HTML；全量重新捕获本轮发现的合格项。
- 不翻页、不展开楼中楼、不另抓回复者主页或附件。接口内嵌预览随原响应保存。
- 新快照仅随原始档案导出，**不进入个人 Canonical、生成网站、搜索或平台导出**。原始档案可能含第三方发言与登录视角信息，不宜直接公开。
- 补齐 API Referer，按目标 UID 与广播／topic ID 去重，并处理旧断点、独立 HTML/API 成败和缺口恢复。

### 抓取与恢复

- 修复终止旧任务、切换登录状态后，新任务仍被旧操作者误拦的问题。核对目标期间禁用旧开始入口，防止预览与实际抓取范围不一致（#32、#33）。继续旧任务仍严格绑定原操作者与目标。
- 对已核验的电影影评“没有访问权限”页面，记录独立失败与缺口，让其他内容继续；普通继续不重复请求，显式重试成功后清除对应缺口，保留历史响应（#34）。
- 修复失败或重试成功响应已经落盘、checkpoint 尚未更新时的恢复状态。一般风控、限流、验证码及操作者切换仍暂停整场任务。

### 导出展示

- Markdown／网站保留短评的中间历史版本，以日期和版本编号区分同日修改。
- 仅在证据一致时合并呈现广播与原页短评来源，避免重复展示，也避免把新短评附到旧广播上。
- 扩展帮助、README 与网站同步说明广播类型、三种模式和原始快照的导出边界。

### 兼容性与安装

- 新档案使用 **bundle/1.5**，新增 `denied` 判定。更新后的工具继续读取旧档案；旧校验器会拒绝新取值，处理新档案请同步更新 parser／specs／import-adapters。
- 旧档案与旧断点不会自动开启回复首屏。新开关不改变已有原始快照，不新增浏览器权限。
- Firefox 包要求 **Firefox 142+**。GitHub Release 提供 Chrome／Edge 与 Firefox 两个 ZIP；应用商店需分别上传审核，不会随 GitHub Release 自动更新。

### 验证范围

- 广播相关抓取、多账号、恢复、UI、vendor 与解析隔离共 344 项定向检查通过。完整扩展套件 2280 项：2279 通过、0 失败，1 项因既有 Node 解压行为差异跳过；CI 另核对两个时区及跨仓库一致性。
- Chrome 实际导出核对了 52 张详情与 52 个回复首屏（含 1 个 personal topic），原始档案完整性及 schema 校验通过。
- 新增量档案的广播标题已核对 Markdown 与搜索；该轮回复开关关闭，不能作为开启后的跨轮跳过实测。
- Firefox 登录态回复抓取，以及两种浏览器完整的跨轮／刷新／暂停重载人工矩阵仍待验收；自动化和打包通过不等同于这些实机检查。
